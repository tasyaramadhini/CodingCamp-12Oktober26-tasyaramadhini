# To-Do List Life Dashboard

## Project Overview
A lightweight personal productivity dashboard built with HTML, CSS, and vanilla JavaScript.

## Technology Constraints
- Use HTML for structure.
- Use one CSS file: `css/style.css`.
- Use one JavaScript file: `js/script.js`.
- Do not use JavaScript frameworks or a backend server.
- Store user preferences, tasks, and quick links in browser Local Storage.
- Keep the website compatible with GitHub Pages.

## Required Features
- Live clock, current date, and time-based greeting.
- Pomodoro focus timer with Start, Stop, and Reset controls.
- Task creation, editing, completion, deletion, and persistence.
- Quick Links that can be added, opened, and deleted.
- Light and dark theme selection.
- Custom greeting name.
- Task sorting.

## Project Structure
- `index.html`
- `css/style.css`
- `js/script.js`
- `.kiro/steering/project.md`
- `README.md`

## Development Guidelines
Keep the interface responsive, accessible, simple to use, and visually consistent. Keep code readable and avoid unnecessary dependencies.
